---

## 🗺️ Guide to the Roadmap

Every item on the roadmap is a GitHub Issue. Each issue is labeled to indicate:

- A **release phase** — where the feature currently stands in development
- A **product area** — which part of the platform it belongs to
- A **digital worker** — which AI agent(s) it affects (if applicable)
- A **deployment type** — whether it impacts Cloud, API, or both

Once a feature ships, it gets the `shipped` label, the issue is closed, and a link to the release notes or changelog is added.

---

## 🚦 Release Phases

| Phase | Description |
|---|---|
| `🔭 exploring` | Under consideration. We're gathering feedback and evaluating whether to build this. |
| `🎨 in design` | We've committed to building it, but are still working out the *how*. |
| `🔬 preview` | Available in limited or beta capacity. No SLAs. Feedback actively encouraged. |
| `✅ ga` | Generally available. Production-ready with full support. |
| `🚢 shipped` | Delivered. Issue closed with changelog link. |

## 📅 Roadmap Structure

The roadmap board is organized by quarter so you can see what's on the near-term horizon vs. what's further out. Items are placed in the column matching their expected delivery quarter.

There is also an **Exploring** column for items that have no committed timeline yet — these are early ideas we're validating with the community.

> **Note:** Items further out on the timeline are more subject to change. We update the board regularly as priorities evolve.
